# SiteCraft — AI-Powered Website Generator

**Generate website layouts from natural-language prompts using AI.**

SiteCraft is a web application that helps users turn a text prompt into a website design and preview. It uses an AI-powered generation workflow to simplify the initial website creation process.

## 🚀 Live Demo

**Live Application:** https://ai-site-generator-chi.vercel.app/

**GitHub Repository:** https://github.com/Arushi-1706/ai-site-generator

## ✨ Features

- **AI-Powered Website Generation:** Generate website content and layouts from a natural-language prompt.
- **Live Website Preview:** View the generated website within the application.
- **HTML Export:** Export generated website code for use outside the application.
- **Project Reset:** Start a fresh project using the New Project option.
- **Error Handling:** Display useful feedback when website generation fails.
- **Autosave and Restoration:** Designed to preserve the current prompt and generated website across page refreshes using browser storage. Verify this behavior in the submitted version before claiming it as tested.
- **Responsive Interface:** Designed as a web-based application; verify its appearance across desktop and mobile screen sizes.

## 🛠️ Technology Stack

- **Frontend:** Next.js and React
- **Language:** JavaScript
- **Styling:** CSS
- **AI Integration:** Google Gemini API
- **Development Tools:** Node.js and npm
- **Deployment:** Vercel
- **Version Control:** Git and GitHub



## ⚠️ Limitations

- Website generation depends on the availability and behavior of the configured AI service.
- Generated output may require manual editing.
- AI-generated content and code should be reviewed before use.
- The application should not be considered a substitute for a complete security review of generated websites.
